# Drawing App

## Descripción
Aplicación interactiva de lienzo para dibujo que permite a los usuarios crear bocetos digitales personalizados, cambiar colores y tamaños de pincel, e importar o exportar imágenes fácilmente.

## User Stories
- Como usuario, quiero poder seleccionar diferentes colores para mi pincel.
- Como usuario, quiero ajustar el tamaño del pincel/trazo para hacer detalles finos o gruesos.
- Como usuario, quiero borrar partes de mi dibujo usando una herramienta de borrador.
- Como usuario, quiero limpiar el lienzo completo para comenzar un nuevo dibujo.
- Como usuario, quiero guardar mi dibujo como una imagen en mi dispositivo.
- Como usuario, quiero importar una imagen para usarla como fondo del lienzo.

## Metodología
Kanban (Enfoque Ágil) — Se utiliza un tablero visual de tres columnas (To Do, In Progress, Done) para gestionar de forma ágil las tareas individuales durante el desarrollo en un periodo corto.
